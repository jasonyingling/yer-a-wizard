# Wand app icon

Created with the built-in image generation tool. Final source: `wand-icon-final.png`. Packaged macOS asset: `WandIcon.icns`. Rebuild with `bash scripts/build-icon.sh`; the main build includes it automatically.

## Original prompt

Create a simple polished macOS app icon for Yer a Wizard. Single elegant wizard's wand diagonally from lower left to upper right, a tapered warm ivory and gold wand with a dark walnut grip, a single small crisp four-point cyan magical sparkle at its upper-right tip. Bold legible silhouette, minimal flat illustration with very subtle dimensional shading. Centered on a deep midnight navy rounded-square icon tile, generous breathing room, transparent outside the rounded square. No text, no letters, no border, no extra objects, no scene or mockup. Square 1024x1024 production app icon.

## Final edit prompt

Keep the diagonal wizard wand, gold and ivory materials, cyan sparkle, and navy background exactly as they are. Remove the checkerboard border entirely. Extend the same solid deep midnight navy background to every edge and all four corners, giving a FULL-BLEED square image, with no rounded tile, no checkerboard pattern, no white border, no transparency. This is a production app icon source. No other changes.
